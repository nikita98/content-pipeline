# Скиллы kp-*

Пока пусто. Порядок разработки и правила — `AGENTS.md`, раздел «Разработка скилла».

Структура скилла:
```
skills/kp-<шаг>/
  SKILL.md
  scripts/      CLI-скрипты (Python 3.10+ или Node 20+)
  references/   справочные файлы, которые скилл читает по необходимости
  assets/       шаблоны
  evals/        тестовые запросы на русском
```
