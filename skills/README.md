# Скиллы kp-*

Порядок разработки и правила — `AGENTS.md`, разделы «Скиллы» и «Разработка скилла».

| Скилл | Что делает | Статус |
|---|---|---|
| `kp-bench` | стенд этапа 3: тесты распознавания, озвучки, очистки звука, монтажа; запись и свод результатов | готов, идут тесты |

Шаги конвейера (`kp-orchestrator` … `kp-funnel`, список — `site/data/steps.json`) пока не написаны.

Структура скилла:
```
skills/kp-<шаг>/
  SKILL.md
  scripts/      CLI-скрипты (Python 3.10+ или Node 20+)
  references/   справочные файлы, которые скилл читает по необходимости
  assets/       шаблоны и входные файлы
  evals/        тестовые запросы на русском: <случай>/case.yaml, prompt.md, graders/
```

Правим только здесь. Копии для агентов: `python tools/install_skills.py [имя]` → `.claude/skills/` и `.agents/skills/` (не в git, `evals/` не копируется).
