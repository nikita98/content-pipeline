# Похожие продукты: сводка (26.11.2026)

Подробности: `research/01-open-source.md` (открытые проекты), `research/02-saas.md` (платные зарубежные сервисы), `research/03-ru-rynok-i-skilly.md` (русскоязычный рынок и готовые скиллы/MCP для Claude). Цены Black Friday у Predis, Submagic, Creatify — перепроверить после распродажи.

## Главное
- **Весь конвейер не закрывает никто.** Open-source проекты покрывают 2–5 шагов, SaaS — до 8–9 из 12.
- **Пусто на рынке:** отдельный шаг проверки качества; ресёрч Telegram-каналов; связка «ресёрч → сценарий → видео → TG-пост + Reels + Threads» на русском; аналитика «ролик → лид → деньги».
- **Главная боль рынка:** кредиты сгорают на неудачных генерациях, трудно вернуть деньги (OpusClip, HeyGen, Creatify, InVideo, Revid, Arcads, Captions).
- **Рынок движется к «Claude + MCP + скиллы»:** у Blotato уже есть пак Claude Skills, у HeyGen, OpusClip, Vizard, Creatify, Revid, Postiz, Predis, Buffer, ChatPlace — MCP. Отличаться нужно методологией, русским языком, Telegram и проверкой качества, а не самим фактом интеграции.

## Что разобрать (кандидаты на скачивание)
1. **OpenMontage** (AGPL, ~72k★) — ближе всех по архитектуре: агент-оркестратор, YAML-пайплайны, Markdown-скиллы, ворота одобрения, бюджет, лучший QA (ffprobe, кадры, звук, субтитры), отдельные инструкции под Claude/Codex/Cursor. Берём идеи, не код (AGPL).
2. **digitalsamba/claude-code-video-toolkit** (MIT) — видеоблок в родном формате Claude Code: скиллы + команды, бренд-киты, версии, дешёвый TTS и аватар на арендованном GPU.
3. **head-of-content + Ootto-AI/claude-content-skills** (MIT) — начало конвейера: ресёрч конкурентов с формулами выбросов (Apify, TubeLab, Gemini, установка в Cowork), цепочка хук → сценарий → подпись → ответ на комментарий.
4. **Официальные Remotion Agent Skills** — база шага монтажа.
5. **claude-shorts (MIT) и Kapwing /shorts-editor (бесплатно)** — нарезка длинного видео и самопроверка кадров/звука с перерендером.
6. **coreyhaines31/marketingskills** (MIT, ~60k★) — шаблоны скиллов текстов, контент-стратегии, лид-магнитов; общий файл контекста клиента.
- Запасные: MoneyPrinterTurbo (MIT, простой движок «тема → ролик»), OpenReply (MIT, замена ManyChat), OpenShorts (MIT, длинное → короткие, публикация в Threads), Postiz (AGPL, публикация в Telegram с MCP).
- Платно на месяц как эталон (решает владелец): ChatPlace Creator.

## Важные оговорки
- **Remotion:** бесплатно для частных лиц и компаний до 3 человек; дальше Creators $25 за место в месяц или Automators от $100/мес.
- **AGPL** (OpenMontage, Postiz, MoneyPrinterV2): нельзя встраивать код в закрытый продукт для клиента без раскрытия исходников.
- **Instagram в РФ:** Meta признана экстремистской организацией — риск для продукта, завязанного только на Instagram.
- **Оплата зарубежных сервисов из РФ** не проверялась — для клиентов в РФ может быть критично.

## Ориентиры по цене нашего продукта (предложение ресёрча, не решение)
- Узкие инструменты $15–40, комбайны $29–99 за соло, агентские ~$200.
- Для эксперта $29–49/мес за скиллы и методологию (сервисы клиент оплачивает сам), для команды $97–199, внедрение под ключ для компаний отдельно.

## Чем можем отличаться
1. Полный цикл с монтажом и отдельным шагом проверки с утверждением человеком.
2. Скиллы-файлы у клиента, без привязки к одному сервису и его кредитам.
3. Telegram наравне с Instagram; ресёрч Telegram-каналов.
4. Аналитика до денег: ролик → кодовое слово → лид → оплата.
5. Позиционирование «качество в голосе эксперта, а не 100 роликов по кнопке».
