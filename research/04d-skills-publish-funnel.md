Платформенные ограничения (из общего знания, документация не сверена): Instagram Content Publishing API требует профессиональный аккаунт и Meta app; видео по публичному URL (подтверждено README drashrafsaiyed); у TikTok Content Posting API непроверенные приложения публикуют приватно, нужен аудит; квота YouTube Data API: upload ~1600 единиц, 10 000/сутки по умолчанию.

Лучший вариант: Postiz как единый слой публикации (MCP/CLI, self-host, AGPL). Подтверждено, что Telegram в нём есть (провайдер в коде, инструкция в доках). Прямой Bot API для Telegram не нужен. Скилл-обёртку (черновик, одобрение, публикация) писать свою по образцу guyaga. TryPost: запасной. Zernio: вариант, если не хотим оформлять свои приложения Meta/TikTok (платный посредник).
