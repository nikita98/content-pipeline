Как подключиться тестировщику

Без консоли (Windows 10/11): скачать установщик ContentPipeline-Setup-…exe со страницы Releases и запустить. «Далее» → папка (лучше латиницей) → галочки компонентов → «Готово». Права администратора не нужны, Python, ffmpeg, Git, Node и auto-editor уже внутри. Интерфейс открывается ярлыком «Конвейер контента» на рабочем столе, закрывается кнопкой «Выход». Файл пока без подписи: если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае». Результаты — «Скачать результаты архивом» и переслать владельцу.

Тестировщикам с git (Windows и macOS): нужны Python 3.10+, Node 22+, ffmpeg и git. Видеокарта NVIDIA — только для Qwen3-TTS.

  1. Склонировать репозиторий: git clone https://github.com/nikita98/content-pipeline
  2. Запустить интерфейс двойным кликом: start-bench.bat (Windows) или start-bench.command (macOS, первый раз — правый клик → «Открыть»). Откроется страница в браузере; окно с сервером не закрывать. В «Настройках» указать имя латиницей и агента. Интерфейс проверит компьютер, поставит пакеты Python, запустит тесты и запишет результаты.
  3. Без интерфейса: поставить скилл в папки агентов python tools/install_skills.py kp-bench, открыть агента (Claude Code, Codex, Kimi Code, OpenCode) в папке репозитория и написать: «запусти тесты стека, я <имя латиницей>».
  4. Для тестов голоса и монтажа прочитать вслух skills/kp-bench/assets/inputs/script_ru.txt на телефон (45–60 с) и записать 15 с свободной речи для клона.
  5. Результаты пишутся в bench/results/. В интерфейсе — «Отправить в git» (если git настроен и есть права) или «Скачать результаты архивом» и переслать владельцу. В агенте — git pull --rebase и git push. Клетка на этой странице окрасится после следующей публикации.
  6. Платные тесты — только после «да» с суммой от того, кто платит. Ключи API — в своё окружение, не в чат и не в репозиторий.
