# Стенд этапа 3

Скилл: `skills/kp-bench/SKILL.md`. Каталог тестов и цены: `site/data/bench.json`. Страница: `site/bench.html`.

- `results/<тест>/<дата>_<тестировщик>_<вариант>.json` — результат прогона (в git).
- `env/<тестировщик>.json` — среда тестировщика (в git).
- `runs/` — аудио, видео, промежуточные файлы (не в git).
- `tools/` — склонированные репозитории инструментов (не в git).

Начать одним из способов:
- без консоли и git (Windows): скачать установщик `ContentPipeline-Setup-<версия>.exe` из https://github.com/nikita98/content-pipeline/releases/latest, запустить, «Далее» до конца, открыть ярлык «Конвейер контента» на рабочем столе. Python, ffmpeg, Git, Node и auto-editor уже внутри; пакеты для тестов — галочки в мастере или раздел «Установка». Результаты — «Скачать результаты архивом» и переслать владельцу. Устройство — `installer/README.md`;
- интерфейс из git-клона (тестировщики с git): двойной клик по `start-bench.bat` (Windows) или `start-bench.command` (macOS) в корне репозитория, затем «Настройки» → имя тестировщика. Описание — `app/README.md`;
- агент: `python tools/install_skills.py kp-bench`, открыть агента в папке репозитория и написать «запусти тесты стека».

- `runs/_log/` — логи задач интерфейса; `runs/export/` — архивы результатов; `runs/_agent/` — задачи для агентов (не в git).
