# Стенд этапа 3

Скилл: `skills/kp-bench/SKILL.md`. Каталог тестов и цены: `site/data/bench.json`. Страница: `site/bench.html`.

- `results/<тест>/<дата>_<тестировщик>_<вариант>.json` — результат прогона (в git).
- `env/<тестировщик>.json` — среда тестировщика (в git).
- `runs/` — аудио, видео, промежуточные файлы (не в git).
- `tools/` — склонированные репозитории инструментов (не в git).

Начать одним из способов:
- интерфейс: двойной клик по `start-bench.bat` (Windows) или `start-bench.command` (macOS) в корне репозитория, затем «Настройки» → имя тестировщика. Описание — `app/README.md`;
- агент: `python tools/install_skills.py kp-bench`, открыть агента в папке репозитория и написать «запусти тесты стека».

- `runs/_log/` — логи задач интерфейса; `runs/export/` — архивы результатов; `runs/_agent/` — задачи для агентов (не в git).
