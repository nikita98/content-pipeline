## Русский голос (research/07-ru-voice.md)
- Основной путь — запись эксперта: DeepFilterNet → ffmpeg loudnorm −14 LUFS → auto-editor для пауз; слова-паразиты — свой скрипт на GigaAM v3 с пословными таймкодами.
- Генерация: облако — ElevenLabs v4 с клоном, запасной для РФ — Yandex SpeechKit v3; локально — Qwen3-TTS + LoRA ударений. Перед синтезом — нормализация текста (rutextnorm) и ударения (silero-stress или ruaccent).
- Не брать для коммерции: Silero, F5-TTS, XTTS-v2. Не брать OpenAI TTS (отключение 06.01.2027) и SaluteSpeech (30.11.2026).
- Проверка озвучки: обратное распознавание GigaAM и сверка с текстом. От эксперта — письменное согласие на синтез голоса.
