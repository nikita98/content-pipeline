# План: конвейер контента

Версия 0.7 · 27.11.2026 · черновик
Веб-страница: https://claude.ai/artifact/6VNrHvwcXVbcU2gBeUGq7B (исходник `site/index.html`)

Данные плана хранятся в одном месте — в файлах `site/data/*.json`. Страница строится из них, этот файл описывает устройство и ссылается на них. Таблицы и списки сюда не копируются.

## Что строим
Набор скиллов SKILL.md, который ведёт эксперта от ресёрча конкурентов до публикации, аналитики и воронки продаж. Один шаг — один скилл `kp-*`, координатор `kp-orchestrator` запускает цикл и останавливается там, где решает человек. Скиллы работают в Claude, Codex, Kimi Code, OpenCode и с моделями DeepSeek. Контент на русском. Площадки: Reels, Shorts и длинное YouTube, TikTok, Threads, Telegram.

Агент 1 — контент (★, шаги 0–13). Агент 2 — воронка (шаги 14–15).

## Как менять
- Шаг, сервис, решение, этап, запись библиотеки — правка в соответствующем JSON. Страница обновится сама после публикации.
- Новое решение — запись в `decisions.json` с датой. Где вариантов несколько, решает владелец проекта.
- Новый инструмент — запись в `library.json` по схеме. В стек — только после проверки по первоисточнику.
- Этот файл меняется, только когда меняется устройство плана.

## Принципы
1. Один шаг — один скилл, вход и выход — файлы в папке клиента.
2. Человек решает на остановках: выбор тем, кодовые слова, сценарий и путь видео, бюджет генерации, утверждение ролика, дата публикации (список — `stop` в `steps.json`).
3. Ничего не публикуется и не оплачивается без «да».
4. Только реальные цифры: не выдумывать метрики, не копировать чужие тексты.
5. Бесплатная замена для каждого платного сервиса, где она есть.
6. Без привязки к одному агенту: только стандарт SKILL.md и MCP, браузер — Claude in Chrome или Playwright MCP.
7. Лицензии: MIT и Apache берём с уведомлением автора, AGPL — только идеи, CC BY — с атрибуцией.
