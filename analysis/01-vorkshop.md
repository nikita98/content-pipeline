## 1. neiro-kontent-menedzher (в архиве также как «Контентщик»)
- **Что это:** скилл «ИИ-агент контент-менеджер под ключ», запуск словом «поехали». Автор — Виктория Матвиенко. Лицензия не указана. SKILL.md 22 КБ + 6 файлов reference.
- **Шаги нашего плана:** 1, 2, 3, 4, 5, 6, 8, 10 (через Submagic), 12 (планер Submagic), 14.
- **Структура:** 10 этапов: анализ конкурентов → 10 тем → CTA → горизонт → тексты TG + Threads → карусели Canva + описания → 3 варианта Reels → видео с аватаром и рилс в Submagic → итоговый анализ → лид-магниты. 5 обязательных остановок.
- **Скиллы:** сам скилл; ссылается на `threads` и `reels`, которых в архиве нет.
- **Файлы reference:** НАСТРОЙКА.md (инструкция ученику), analiz_konkurentov.md, kontent_pravila.md, karuseli_canva.md, reels_i_video.md, lidmagnity.md.
- **Библиотеки и программы:** приложение Claude (Cowork), Node.js (для Submagic MCP).
- **Внешние сервисы:** Claude in Chrome, Canva (коннектор), Higgsfield (коннектор: клон голоса, generate_audio, media_import_url, модель говорящей головы), Submagic (MCP по API-ключу через конфиг), Google Drive (по желанию).
- **Модели:** озвучка `text2speech_v2_elevenlabs` через Higgsfield; видеомодель говорящей головы Higgsfield.
- **Агенты:** только Claude: TaskCreate, Claude in Chrome, коннекторы claude.ai, Cowork.
- **Файлы между шагами:** `конкуренты.txt`, `стиль_референс.jpg`, `аватар.txt` (voice_id, voice_model, aspect = 9:16), папки `Фото_аватар/`, `Готовые_ролики/`, `Материалы/`. Выход: тексты в TXT, анализ и лид-магниты в PDF, ссылки на карусели.
- **Правила:** без длинного тире; только реальные цифры; одно кодовое слово на тему во всех форматах; таблица «тема → кодовое слово → что обещано → кем задан CTA»; лид-магнит делается только под CTA, придуманный агентом; фото автора выбирается случайно, без повторов; в планер — только после подтверждения.
- **Горизонт:** 1 день = 1 тема (TG, Threads, карусель, описание, 3 Reels); 3 дня = 3 темы; неделя = 3 темы на 7 дней с ротацией углов.
- **Берём (идея):** остановки, маппинг горизонта, таблица CTA, метод «залетело», правила текста, файл аватара.
- **Не берём:** монолитный формат, жёсткую привязку к Claude и Canva.
- **Слабые места:** один большой файл; нет скиллов `threads` и `reels`; сбор данных через браузер автора; нет раскадровки, проверки качества, аналитики; монтаж только через Submagic.
- **Открытые вопросы:** где взять скиллы `threads` и `reels`; лицензия на использование.

## 2. Ресёрчер (researcher)
- **Что это:** скилл-«сотрудник» для разбора конкурентов. SKILL.md 6 КБ + reference/analytics_method.md.
- **Шаги нашего плана:** 1, 2.
- **Структура:** онбординг (ниша, 3–7 конкурентов, главный вопрос) → полный разбор: проверка инструментов → YouTube → Instagram → Telegram → синтез 5–10 смыслов → сохранение → 3–5 выводов. Быстрые режимы: разбор одного канала, «что залетает в нише», обновить смыслы.
- **Библиотеки:** Python + openpyxl (таблица аналитики).
- **Внешние сервисы:** Claude in Chrome; при недоступности — web search + fetch.
- **Агенты:** Claude (TaskCreate, Claude in Chrome).
- **Файлы:** `Команда/Ресёрчер/память.md`, `конкуренты.md`, `отчёты/разбор_<дата>.md`, `отчёты/аналитика_<дата>.xlsx`; `Второй мозг/смыслы/смыслы_<дата>.md`.
- **Метод:** «залетело» = выше медианы канала в 1,5+ раза (у контент-менеджера — в 2–3 раза); YouTube — 10–20 роликов за 30 дней + пики; формулы заголовков.
- **Берём (идея):** «Второй мозг/смыслы» как общий источник для других шагов; быстрые режимы; xlsx с метриками.
- **Слабые места:** только Claude; порог расходится с контент-менеджером.

## 3. Маркетолог (marketer)
- **Что это:** скилл для продающих материалов. SKILL.md 6 КБ + reference/struktury.md.
- **Шаги нашего плана:** 14; остальное вне конвейера (лендинги, КП, аудит продаж, стратегия запуска).
- **Режимы:** продающий пост, лид-магнит, лендинг (текст + HTML одним файлом), презентация/КП (pptx или HTML), аудит «почему не покупают», стратегия запуска на 2–4 недели.
- **Файлы:** `Команда/Маркетолог/досье.md`, `работы/`; читает `Второй мозг/смыслы/`.
- **Структуры:** продающий пост (крючок → узнавание → поворот → решение → доказательство → CTA), прогревающий пост, лид-магнит, лендинг из 9 блоков, КП из 6 блоков, цепочка аудита «охваты → прогрев → оффер → цена → точка продажи → обработка заявок».
- **Берём (идея):** структуру лид-магнита для шага 14; досье как часть паспорта.
- **Открытый вопрос:** включать ли режимы вне конвейера в продукт.

## 4. Обработка заявок (sales, «Продажник»)
- **Что это:** скилл для ответов клиентам и ведения заявок до оплаты. SKILL.md 6,6 КБ + reference/etapy_prodazh.md.
- **Шаги нашего плана:** 15 и пункт заказчика «все заявки в CRM + ИИ-боты».
- **Уровни:** 1 — работа с присланными переписками, скринами, аудио; 2 — прямая работа в Telegram через Telegram MCP, по умолчанию черновики с отправкой после «ок».
- **Файлы:** `Команда/Продажи/скрипт.md`, `заявки.md` (журнал: клиент, этап, дата, следующий шаг), `диалоги/`; читает `Команда/Маркетолог/досье.md`.
- **Этапы:** новая заявка → квалификация → презентация → возражения → закрытие → молчание (2–3 касания).
- **Берём (идея):** журнал заявок, режим черновиков, этапы и формула возражений.
- **Слабые места:** CRM как отдельной системы нет — журнал в markdown.

## 6. Видеостудия: «Монтаж видео голосом и текстом» (PDF)
- **Что это:** инструкция «Лаборатория Блог & AI»: Claude Code собирает видеостудию на Remotion в отдельной папке. Не скилл, а задание для Claude Code внутри PDF.
- **Шаги нашего плана:** 10, частично 11 (безопасные зоны).
- **Программы и библиотеки:** приложение Claude, вкладка Code, режим Local; Node.js ≥ 20 (winget или Homebrew); `npx create-video@latest` (шаблон Blank, TailwindCSS, Remotion Skills); `@remotion/captions`, `@remotion/install-whisper-cpp`; модель Whisper без суффикса .en (large-v3 или medium), больше 1 ГБ.
- **Структура папки:** `public/` (исходники), `out/` (MP4), `templates/` (шаблоны), `src/`, `CLAUDE.md` (цвета, шрифты, правила).
- **Правила:** имена файлов латиницей без пробелов; сначала показ в Remotion Studio (localhost:3000), рендер только по команде; расшифровку показывать до наложения; одна задача — один запрос.
- **Возможности:** субтитры с подсветкой слов, оверлеи и выноски, заставки и финальные экраны, инфографика, зумы и дрожание, обрезка, склейка, ускорение, вырезание пауз длиннее 1,5 с, музыка 15% с затуханием, перегонка в 1:1 и 16:9, безопасные зоны Reels 250 px сверху и 400 px снизу; шаблоны «сохрани как шаблон» с вынесенными настройками.
- **Лицензия Remotion:** бесплатно для частных лиц и небольших команд (по сайту Remotion — до 3 человек).
- **Агенты:** написано под Claude Code; сам Remotion от агента не зависит.
- **Берём:** почти целиком как основу шага 10: структуру папки, правила, библиотеку запросов, шаблоны.
- **Слабые места:** установка через задание в PDF, а не скилл; первый запуск 10–25 минут; нужна проверка на Windows.
