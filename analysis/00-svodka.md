## Что переписывать под русский язык
- Скрипты сбора и анализа HoC: зашит английский, регулярное выражение ключевых слов не видит кириллицу.
- Майнинг хуков CCS: английские паттерны и словарь.
- Субтитры CVT: при выравнивании по сценарию остаются только латинские буквы, кириллица выбрасывается.
- Чистильщик ИИ-стиля CCS и линтер текста CVT: английские списки.
- Описания скиллов (триггеры) CCS и HoC: на английском, русский запрос может не вызвать скилл.

## Варианты для решения владельца проекта
1. **Порог «залетело»:** выше медианы аккаунта в 1,5 раза (Ресёрчер ВШ) / в 2–3 раза (контент-менеджер ВШ, CCS) / выше среднего по выборке на 2 стандартных отклонения (HoC).
2. **Сбор данных конкурентов:** браузер (Claude in Chrome / Playwright) / Apify / TubeLab для YouTube. Telegram: у воркшопа публичная веб-версия канала `https://t.me/s/<канал>` (fetch или браузер) — 20–30 последних постов, просмотры и реакции, без платных сервисов; в репозиториях конкурентов источника нет.
3. **Разбор видео конкурентов:** Gemini по видео (HoC) / без видеомодели: FFmpeg находит смены сцен, берёт до 20 ключевых кадров, агент смотрит кадры сам + транскрипт Whisper (схема `video-reference-analyst` + `scene_detect` / `frame_sampler` в OM, только идея). Второй вариант не требует Gemini; звук, кроме речи, теряется.
4. **Генерация видео и голоса:** Higgsfield (ВШ) / HeyGen / свои модели на арендованном GPU через Modal или RunPod (CVT).
5. **Озвучка на русском:** ElevenLabs / Qwen3-TTS с клоном голоса / Piper локально. Качество русского нигде не проверено.
6. **Монтаж:** Remotion (ВШ, CVT, OM) / moviepy без Node (шаблон CVT для шортов) / Submagic.
7. **Память и файлы проекта:** папка клиента с markdown (наш план) / Obsidian как в CCS.
8. **Режимы вне конвейера** (Маркетолог, Коуч, платная реклама, коллаборации): включать ли в продукт.
