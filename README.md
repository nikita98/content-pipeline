# Конвейер контента

Скиллы для полного цикла контента эксперта: ресёрч конкурентов → идеи → тексты → карусели → сценарии → раскадровка → генерация → нарезка → монтаж → проверка → публикация → аналитика → лид-магниты → воронка. Работают в Claude, Codex, Kimi Code, OpenCode и с моделями DeepSeek.

Статус: этап 3 — тест голоса, генерации и монтажа на стенде. Текущее состояние — `docs/status.md`. Правила и полная карта для ИИ-агентов — `AGENTS.md`.

## Структура
```
AGENTS.md            правила и карта репозитория для любого ИИ-агента
CLAUDE.md            подключает AGENTS.md для Claude Code + дополнения для Claude
docs/plan.md         устройство плана и ссылки на данные
docs/status.md       где мы, что дальше, открытые вопросы
site/index.html      веб-страница плана; site/bench.html — страница стенда
site/data/*.json     данные: шаги, сервисы, итоги, агенты, правила, решения, этапы, стек, библиотека, стенд
analysis/            разборы готовых конвейеров
research/            ресёрч рынка и инструментов
skills/              наши скиллы kp-* (сейчас kp-bench)
bench/               результаты тестов стенда
app/                 локальный интерфейс в браузере (app/README.md)
installer/           Windows-установщик (installer/README.md)
tools/               служебные скрипты (установка скиллов в папки агентов)
start.bat, start.command   запуск интерфейса двойным кликом
```

## Посмотреть страницу локально
```
python -m http.server 8000 --directory site
```
Открыть http://localhost:8000. Страница грузит данные через fetch, поэтому открывать файл напрямую (file://) не получится.

## Запустить интерфейс
Двойной клик по `start.bat` (Windows) или `start.command` (macOS), либо `python app/server.py`. Установщик для Windows — https://github.com/nikita98/content-pipeline/releases/latest.
