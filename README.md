# Конвейер контента

Скиллы для полного цикла контента эксперта: ресёрч конкурентов → идеи → тексты → карусели → сценарии → раскадровка → генерация → нарезка → монтаж → проверка → публикация → аналитика → лид-магниты → воронка. Работают в Claude, Codex, Kimi Code, OpenCode и с моделями DeepSeek.

Статус: проектирование. Текущее состояние — `docs/status.md`.

## Структура
```
AGENTS.md            правила для любого ИИ-агента
CLAUDE.md            подключает AGENTS.md для Claude Code
docs/plan.md         устройство плана и ссылки на данные
docs/status.md       где мы, что дальше, открытые вопросы
site/index.html      веб-страница плана
site/data/*.json     данные: шаги, сервисы, итоги, агенты, правила, решения, этапы, стек, библиотека
analysis/            разборы готовых конвейеров
research/            ресёрч рынка и инструментов
skills/              наши скиллы kp-* (пока пусто)
```

## Посмотреть страницу локально
```
cd site
python -m http.server 8000
```
Открыть http://localhost:8000. Страница грузит данные через fetch, поэтому открывать файл напрямую (file://) не получится.
